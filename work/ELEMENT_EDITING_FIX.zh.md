# 0.0.12 创作要素编辑与全文阅读修复

日期：2026-10-21。用户反馈：创作要素建立后无法修改，长篇内容无法展开阅读。

## 检查范围与发现

| 页面 | 原有问题 | 修复后的入口 |
| --- | --- | --- |
| 角色 | 详情全部只读；长文本只有两行；前端未调用已有修改接口 | 详情上方“查看全文 / 编辑”；姓名、年龄、性别、外貌、性格、背景、动机、弧光、外在标记、备注可修改 |
| 世界观 | 卡片两行截断，无点击详情；前端未调用修改接口 | 卡片“查看全文 / 编辑”；分类、名称、描述、标签可修改 |
| 科学设定 | 无详情、无前端修改调用、无后端修改接口 | 卡片“查看全文 / 编辑”；类别、名称、描述、参考资料可修改 |
| 伏笔 | 卡片两行截断，无详情和修改接口；已放弃记录没有展示列 | 卡片详情；标题、描述、优先级、四种状态、预计回收章节可修改；增加已放弃列 |
| 人物关系 | 图谱无关系详情编辑入口；已有接口字段不完整 | 右侧关系列表详情；关联角色、类型、说明、强度、起止时间可修改 |
| 叙事记忆 | AI 建立的条目无后续编辑入口 | 普通列表和搜索结果均可打开全文并修改分类、内容；保留来源章节 |
| 时间线 | 只有建立入口，未接入已有修改接口 | 事件详情；年份、标题、描述、重要程度可修改 |
| 章节正文、标题、大纲与五维字段 | 已具备编辑与持久保存流程 | 保留原保存流程；大纲和五维长文本增加展开编辑 |
| 设置、目标字数、项目封面、会话标题 | 已有修改入口与保存逻辑，不存在本次“建立后不可修改”的相同缺口 | 沿用现有流程 |
| 项目概览统计、一致性检查、导出记录、关于 | 计算结果或输出记录，不是独立创作要素的编辑表单 | 本次没有将这些结果改成编辑数据 |

## 行为与数据约束

- 详情默认按段落展示完整内容，保留空格、空行和换行，支持纵向滚动和全屏。
- 编辑时预填原内容；长文本可展开并纵向拖大；表单内容滚动，操作按钮保持可见。
- 提交仅发送实际改变的字段，更新原 ID，不建立替代条目。其余字段、章节关联、记忆来源与创建时间保持不变。
- 修改接口统一白名单、必填、枚举与整数范围校验；不存在的条目返回 404，空更新返回 400；SQL 引用保留字 references。
- 取消有未保存改动时显示放弃提示；保存失败保留输入；保存期间防重复提交与关闭。
- AI/手动刷新不会卸载已有的编辑弹窗；角色保存后保留所选角色。编辑表单打开期间暂缓自动云端替换，成功保存仍通过原事件触发自动上传。
- 无数据库结构迁移。版本同步为 0.0.12；没有覆盖现用应用、修改真实作品或删除 Google 数据。
