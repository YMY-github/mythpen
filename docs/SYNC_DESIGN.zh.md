# 同步、备份与恢复规则

这是社区开发预览。作品先保存在本机；Google Drive 同步按作品启用，自动同步默认关闭。同步对象为作品数据库与封面，数据库内的章节、人物、世界观等内容一起保存。全局设置、AI 密钥、Google Token 和客户端配置不进入作品快照。

## 第一次使用

在“设置 → Google Drive”导入桌面 OAuth 配置，用 Google 账号授权。选择作品，点击同步完成首次上传；另一台电脑使用同一个 Google 应用配置和账号，在云端作品列表导入。两台电脑独立登录，不复制 Token。应用私有空间不会显示为普通 Drive 文件夹。

状态栏显示待同步、同步中、云端有更新、冲突或错误，并可打开设置。状态显示基于最近一次检查，不代表持续在线的实时协作。

## 自动上传与远端更新

首次启用作品同步后可以勾选自动同步。保存后等待约 30 秒上传；后台约每 2 分钟检查，应用回到前台或恢复联网也会触发受节流的检查。应用完全退出期间不会上传。未保存的编辑不在快照中。

远端有更新时，程序提示确认下载。先保存所有编辑并等待 AI 写作完成，再应用云端版本。程序校验作品身份、文件大小、SHA-256 和数据库完整性，核对本机内容未变化，并在替换前保存本机备份。不会依靠设备时间选择覆盖内容。

两台设备同时修改可能出现冲突。可将选定云端分支保留为独立作品副本，或者明确以本机版本解决冲突；原有云端修订仍保留。选择前应先分别保存需要的内容。这不是逐段合并或多人实时编辑。

## 离线备份与恢复

本地备份可在未连接 Google 时创建、查看和恢复。恢复前必须保存编辑；原本机版本会先保存为恢复点。损坏备份保留但禁止应用，其他有效备份仍可使用。恢复日志支持替换中断后的启动重放。

本地备份保存在同一个应用数据目录，不代替异地备份。当前不自动清理本地备份，可占用磁盘空间。云端恢复完成后属于新的本机工作，之后同步会保留其来源关系。

## 云端历史清理

不自动删除云端历史。先输入保留数量（2–1000，默认 30）并预览，再明确确认永久删除。预览后云端或本机有变化会拒绝旧计划，必须重新预览。

保留当前最新分支、当前本机内容对应版本、当前设备基线、最近指定数量以及最近 24 小时版本；存在未解决分叉时不清理。该数量是最低保留目标，不保证恰好只剩这些版本。清理不会删除当前本机作品。

应用私有空间不支持移入回收站，清理是永久删除。清理过的祖先可能仍被长期离线设备引用；再次同步时会保守提示冲突，而不会猜测覆盖。清理前建议让所有设备同步，并另存所需版本。mock 测试覆盖实际删除流程；真实 Google 只验证预览，尚未执行永久删除验收。

## 限制与隐私

- 单次快照原始文件合计上限 64 MiB；编码后的传输大小更大。超过 5 MiB 的 JSON 使用可恢复上传，分块为 8 MiB；网络中断可查询服务端进度并有限重试。退出程序后的上传会在下次重新开始，不承诺跨进程续传。
- 每次仍需扫描并校验历史；最多 10000 个远端文件。历史正文逐份处理，不同时驻留全部历史，但历史越多，耗时和流量越大。没有增量索引和差量传输。
- 断网、限流和临时服务故障退避重试；授权、磁盘、格式等永久故障停止自动重试并提示处理。
- Google Token 使用 macOS 钥匙串或 Windows 系统凭证存储，无明文 Token 文件回退。系统提示需用户本人处理。
- 只申请 `drive.appdata`。作品通过 HTTPS 上传；当前没有客户端端到端加密，不应宣称云端服务无法读取内容。
- 诊断面板只展示平台、版本、状态、计数和限制；不主动发送遥测，不包含账号、作品名、正文、路径或 Token。
- 同一应用数据目录不支持多个独立后台服务并发使用。Windows ARM、多用户协作和移动端不在当前验收范围。

官方协议参考：[应用私有数据](https://developers.google.com/workspace/drive/api/guides/appdata)、[上传与恢复](https://developers.google.com/workspace/drive/api/guides/manage-uploads)。
