## 运行

需要 Node.js 20+ 和项目要求的 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm dev:all
pnpm test:sync
pnpm exec tsc --project tsconfig.app.json --noEmit
pnpm build
```

`dev:all` 不再执行 seed。默认浏览器端口 5173，后端 3101。本轮预览运行在 5174 并使用工作目录中的专用测试数据；不会读取用户原版作品。
