# 开发状态与接续说明

更新于 2026-10-19（本机时区）。当前预览版本 0.0.10，基于上游 niyongsheng/mythpen v0.0.9、提交 be30119f85fe5d1206c80f7202cab1d1bc0d9ba9。保留原作者历史和许可证声明。

## 最新产品要求

用户明确选择“主要轮流使用，自动上传和打开时下载即可”。已将原手动备份/版本工作流改为自动云文档：连接 Google 后所有作品自动同步，打开时自动发现并下载最新稿；不再要求开启每部作品、选择版本、手动下载或设置保留数量。两边都改过时采用云端稿，本机稿先存恢复副本。不是同时逐字合并协作。

## 已实现

- 约 0.5 秒正文/标题/大纲自动本机保存和草稿持久化队列；单字、空格、空稿也会同步；序列化写入、中文输入法保护、重启恢复未完成草稿。
- 保存后排队自动上传，前台每约 3 秒协调当前作品；打开前同步门禁、回到前台/恢复联网检查、自动发现与导入。
- 云端优先自动应用；恢复点、哈希与数据库校验、请求取消和写入/AI 防护；同名不同 ID 隔离。
- 云端每设备维护一份当前文件并 PATCH 更新；大文件支持可恢复 PATCH；旧预览不可变历史原样保留，不每次改字创建完整历史文件。
- 设置界面简化为 Google 连接和自动同步状态，移除普通版本、手动更新、历史清理与本地备份面板；保留后台恢复能力。
- 云端确认与本机保存状态分开，防止本机保存就显示“已同步”；保留当前章节，避免旧请求覆盖切换后的项目。
- 独立应用标识 community.mythpen.sync.dev、默认目录 ~/.mythpen-sync-dev、后台端口 3101；不覆盖原版 Mythpen。
- Google OAuth/PKCE/刷新、系统凭证存储、代理适配及去敏诊断继续沿用；快照排除配置与密钥。

- 8 项内存 DOM 编辑器集成测试通过：单字自动保存、空格/空稿、连续输入旧响应、中文输入法、云端正文刷新、无版本选择设置、打开前门禁、本机保存不假报云端成功。

## 构建与接续

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test:sync
pnpm test:editor
pnpm exec tsc --project tsconfig.app.json --noEmit
pnpm build:sidecar
pnpm test:sidecar
pnpm tauri build
```

环境：Node 24、pnpm 10.10.0、Bun 1.4.3、稳定 Rust。先读 [同步规则](SYNC_DESIGN.zh.md) 和 [桌面构建](DESKTOP_BUILD.zh.md)，检查现有提交/构建再继续。不要重复创建 Google 项目、删除真实云端数据或替换正在使用且未保存的应用。
